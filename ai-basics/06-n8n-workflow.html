n8n 与工作流编排：把 AI 装进业务流水线

约 7 分钟 · 关键词：n8n、低代码编排、触发器、Dify / Coze

Agent 解决"单次任务"，编排解决"天天都要跑的事"

Agent 擅长开放性任务：目标模糊、路径未知，让它自己边想边干。但企业里大量需求是固定流程：每天早上汇总舆情 → 交给 AI 分类打标 → 推送到企微群；客户表单一提交 → AI 提取字段 → 写进 CRM → 触发回访。这类事要的是稳定、可审计、可重跑，而不是"智能发挥"。

这就是工作流编排的领地。代表工具：n8n（开源、可自部署，节点生态最丰富）、Dify（偏 LLM 应用编排）、Coze（字节系，上手快）、Zapier/Make（海外 SaaS 系）。

n8n 的定位：AI 只是画布上的一个节点

n8n 里有几百个现成节点（邮件、数据库、飞书、GitHub……），AI 模型调用只是其中一类。这带来两个工程好处：

  • AI 放在"该聪明"的一步：分类、摘要、抽取交给模型；取数、写库、通知交给确定性节点——不该让模型干的事，一根线都别给它；
  • 失败可处理：每个节点可以配重试、降级、告警，流程像传统后端任务一样可控。

编排 vs Agent：怎么选？

工作流编排（n8n 等）自主 Agent
路径事先画好，固定模型现场规划，动态
可控性✅ 强，逐步可审计⚠️ 弱，行为不可完全预测
适合高频、规则清晰的重复流程开放性、一次性的复杂任务

两者也在融合：n8n 里可以嵌入一个"AI Agent 节点"处理模糊步骤；Agent 框架里也可以调用一条固定工作流。实践准则：能画清楚流程的用编排，画不清楚的才交给 Agent。

✅ 一句话记忆：编排是"确定性的流水线 + 少量 AI 调味"，Agent 是"不确定性的探索者"。企业落地大多数从前者起步，因为它可控、可解释、出了错知道断在哪。
