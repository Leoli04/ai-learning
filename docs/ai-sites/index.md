> 约 8 分钟 · 关键词：AI 站点、资源导航、Agent Skills、核实日期

信息不是不够，而是太散：模型在 Hugging Face、论文在 arXiv、榜单在竞技场、教程在某个人的博客里、工具在 GitHub 上。这张地图把值得长期关注的站点按用途收在一起，**每个都写清"为什么值得看"，而不是只丢一个链接。**

## 关于"需代理"标记

被标记为「需代理」的站点，在国内网络环境下直连不可达（实测表现是连接超时），**不代表站点有问题或不可靠**。这类站点通常是最权威的一批——Hugging Face、arXiv 以外的论文聚合站、竞技场榜单、海外技术社区。

反过来，「直连」标记意味着国内网络可直接访问，包括不少中文站点与国内可直连的海外服务。

## Skill 该去哪找：从规范到市场的四层

先一句话说清 Skill 是什么：它是一个文件夹，里面放着 `SKILL.md`（写明什么时候该用它、怎么用）以及可选的脚本与模板，Agent 按需加载。它和 MCP 的分工是——**MCP 给 Agent 接的是外部系统，Skill 给的一般是内部作业手册**；前者解决"够得着什么"，后者解决"这事该怎么做才不出错"。原理在《AI 基础》第 8 篇里展开过。

找 Skill 的地方按可信度分层，顺序有讲究：

    <tr><th>层</th><th>去哪</th><th>什么时候用</th></tr>
    <tr><td>规范</td><td>agentskills.io</td><td>自己动手写 Skill 之前必读，字段定义与目录约定都在这里定死</td></tr>
    <tr><td>官方仓库</td><td>Anthropic 官方 Skill 仓库</td><td>抄最权威的写法，含文档四件套、规范与最简模板</td></tr>

如果是第一次装，从官方仓库里的 `skill-creator` 开始：它会反过来问你流程、生成目录结构、把 SKILL.md 写好。与其装十个别人的，不如先学会写一个自己的。

## 装 Skill 之前，先看一眼它的 scripts 目录

这一节不是免责声明，而是这个类目最容易出事的地方。

Skill 和提示词不一样：**它可以带可执行代码，而 Agent 会真的去跑。** 一个叫"帮我整理文档"的 Skill，如果 `scripts/` 里藏着读取凭据或批量删除的脚本，光看名字是看不出来的。

装之前至少过这四关：

- **有没有扫描结果**：ClawHub 与 SkillHub 都提供病毒扫描与"良性"标记，优先选带标记的
- **权限是否相称**：一个文档处理技能却申请全盘读写权限，这就是红旗，直接放弃
- **来源与更新**：官方或高星开发者，且近期有维护；长期停更的要谨慎
- **自己再审一遍**：本机若装了安全审计类技能，装之前先跑一次，成本很低

可信度的优先级很好记：**客户端内置技能市场 > 国内官方社区 > 官方注册中心 > 其他第三方渠道**。

::: tip
这张地图的价值不在于"收集得多"，而在于**每一条都带一句判断**：它适合谁、解决什么问题。如果只想收藏一堆链接，浏览器书签会比它更方便。
:::
