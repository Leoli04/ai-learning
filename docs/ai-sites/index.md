# AI 资源地图

> 约 6 分钟 · 关键词：AI 站点、资源导航、Agent Skills、核实日期

信息不是不够，而是太散：模型在 Hugging Face、论文在 arXiv、榜单在竞技场、教程在某个人的博客里、工具在 GitHub 上。这张地图把值得长期关注的站点按用途收在一起，**每个都写清"为什么值得看"，而不是只丢一个链接。**

下面所有条目都逐条联网核实过可达性，并标注了是否需要代理。用搜索框或标签筛一下就够，不用从头读到尾。

## 关于"需代理"标记

被标记为「需代理」的站点，在国内网络环境下直连不可达（实测表现是连接超时），**不代表站点有问题或不可靠**。这类站点通常是最权威的一批——Hugging Face、arXiv 以外的论文聚合站、竞技场榜单、海外技术社区。

反过来，「直连」标记意味着国内网络可直接访问，包括不少中文站点与国内可直连的海外服务。

站点会关停、会改名、会被收购。这张地图上就有两个真实例子：

## Skill 这一类，单独写成了一篇

Skill 是这个地图里唯一"先看安全、再谈好不好用"的一类：它不是一个链接，而是一个可以带可执行代码的目录，**Agent 会真的去运行它**。所以这一类不在这里给一句判断就完事。

按可信度分层，大致是这四个地方：

  <table>
    <tr><th>层</th><th>去哪</th><th>怎么用</th></tr>
    <tr><td>规范</td><td>agentskills.io</td><td>自己动手写之前必读，字段与目录约定都在这里定死</td></tr>

    <tr><td>分发与市场</td><td>skills.sh · ClawHub · 腾讯云 SkillHub · 复旦 DataHub</td><td>要现成能力时按榜单与评分挑，别见到就装</td></tr>
    <tr><td>精选集</td><td>Awesome Agent Skills · Superpowers · Hugging Face · Trail of Bits</td><td>想成体系地装一套，比如开发方法论或安全审计</td></tr>

装之前的四关核验、怎么判断一个技能值不值得装、装完怎么管住数量——都在最后一篇里展开：**Skill：去哪找，装之前查什么**。

::: tip
这张地图的价值不在于"收集得多"，而在于**每一条都带一句判断**：它适合谁、解决什么问题。如果只想收藏一堆链接，浏览器书签会比它更方便。
:::

这张地图里的站点按用途分八类。其中五类最需要展开讲——**模型与数据、论文与前沿、评测与榜单、学习与社区、Agent Skills**，因为它们的用法有明确的顺序和坑，接下来的五篇逐个说清。剩下的**工具与框架、资讯与社区、中文生态**，一句判断已经够用；而工具这一类的重点不是"收藏哪个站"，而是动手做一遍，所以交给两个系列长文：《DeepSeek Harness 通俗图解》讲 Agent 框架怎么组装，《企业知识库实战》讲 RAG 与检索怎么落地。
