DeepSeek Harness
通俗图解学习笔记

DeepSeek 官方开源的 Agent 框架（dsh）——"一切皆插件"。本系列用类比 + 图解，把它的架构掰开揉碎讲清楚。全部图解为手绘 SVG，无外部依赖，离线可读。

01

什么是 Agent Harness？

LLM 是发动机，Harness 是整台车——为什么大模型外面必须套一层"工作服"

 02

一切皆插件：没有特权核心

模型、工具、会话、甚至主循环都是插件——Cordis 框架与可逆 effect

 03

启动分层：Profile / Bundle / Patch

像叠千层饼一样组装系统，上层永远可以覆盖下层，还支持热重载

 04

能力接缝（Capability Seam）

Definition / Provider / Consumer 三角色——换一个零件，改的是整个产品

 05

事件三域与 Turn 执行流

session / agent / capability 三个域，一次任务从 turn/start 到 turn/end 的完整流水线

 06

Session Log：唯一事实源

"Model-visible means logged"——模型看见的一切，都必须有据可查

 07

动手实践：10 分钟跑起来

npx 一把梭，配 Key、选工作区、发任务，再加三个值得马上试的命令
